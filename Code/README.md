`Example.R` is just a copy of the example conducted in the documentation of the `seine` package.

`Synthetic_experiments.R` presents the synthetic dataset as described in Section 4 and loosely inspired by the Italian constitutional referendum.

`Synthetic_experiments_exponential.R` presents the synthetic dataset of Appendix A.

`Texas_regression.R` calls the Texan dataset to experiment with different estimations.

`Replicates.R` replicates the `Synthetic_experiments.R` script in order to study the distribution of estimates as new synthetic datasets are generated.
